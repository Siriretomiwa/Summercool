# Downloadable Theme Package

The ZIP is intentionally **not stored in git** (GitHub web editor cannot edit binary files).

Generate it locally from source:

```bash
./scripts-package-theme.sh
```

This creates:
- `dist/summercool-onepage-theme.zip`
- `dist/summercool-onepage-theme.zip.sha256`

Upload ZIP in **WordPress Admin → Appearance → Themes → Add New → Upload Theme**.
